## 中文说明

### 功能概览

| 功能 | 说明 |
|---|---|
| 🌏 双国家题库 | 中国大陆 CRAC 2025（A/B/C）/ 美国 FCC（T/G/E） |
| ✅ 真·多选题 | 独立勾选+取消，全对才得分 |
| 🌐 中英双语（可开关） | FCC T级 409 题中文翻译，启动器切换 |
| 🔒 隐私外置 | 进度存 personal.dat，工作区零隐私 |
| 📦 单文件启动器 | 一个 exe 双击即用 |
| 🚫 免 UAC | 无需管理员权限 |
| 🆔 身份证校验 | GB 11643 校验和 |
| 📊 实时进度 | 标题栏显示答题进度 |
| 📝 错题本增强 | 多选显示答案组合 |

### 快速开始

**方式一：单文件版（推荐）**

1. 下载 `release/Launcher.exe`
2. 放到任意可写目录，双击运行
3. 选择题库 → 点【启动模拟考试】

**方式二：文件夹版**

1. 下载 `release/` 目录全部文件
2. 运行 `install-first-run.bat`
3. 用 `BankSwitcher.exe` 切换题库

### FCC 等级对应

| 界面 | CRAC | FCC |
|---|---|---|
| A类 | A类（初等） | T=Technician |
| B类 | B类（中等） | G=General |
| C类 | C类（高等） | E=Amateur Extra |

### 考试参数

| 题库 | 题量 | 时间 | 通过 |
|---|---|---|---|
| CRAC A类 | 40题 | 40分钟 | 答对30 |
| CRAC B类 | 60题 | 60分钟 | 答对45 |
| CRAC C类 | 90题 | 90分钟 | 答对70 |
| FCC T级 | 35题 | 30分钟 | 答对26 |
| FCC G级 | 35题 | 30分钟 | 答对26 |
| FCC E级 | 50题 | 60分钟 | 答对37 |
