# CRAC/FCC 模拟考试系统 · 单文件版 使用说明

**CRAC模拟考试_单文件版.exe**（约 14 MB）——一个文件包含全部内容：
模拟考试程序（BI2XM 魔改版增强 exe + 补丁库）、CRAC 2025 与 FCC 双题库（英文版+中英双语版）、
题库切换与导入、隐私数据外置、**双语开关**。

## 快速开始

1. 把 exe 放到任意可写目录（如 D:\火腿无线电\），双击运行
2. 首次运行自动展开全部文件到旁边的 sim_app\ 子目录
3. 点【启动模拟考试】即可；用完退出模拟软件后回到启动器窗口，
   你的登录信息与学习进度自动保存到旁边的 **personal.dat**，并从 sim_app 清除

## 功能

| 功能 | 说明 |
| --- | --- |
| 双国家题库 | 中国大陆 CRAC 2025（A 683 / B 1143 / C 1282 题，含 542 真多选）/ 美国 FCC（T 409 含中英双语 / G 423 / E 599） |
| FCC 对应关系 | 界面 A类=T级 Technician、B类=G级 General、C类=E级 Amateur Extra（FCC 模式下卡片显示 T/G/E 标签） |
| 多选题 | 独立勾选/再点取消，判分"全对才得分"，错题本正确显示答案组合 |
| 中英双语（可开关） | 启动器复选框"FCC 题库显示中文翻译"：勾选=T级全部 409 题中英双语（英文下方附中文）；取消勾选=纯英文原版 T/G/E 题库。切换时学习进度自动迁移 |
| 隐私外置 | 每次退出把进度打包到 personal.dat 并清理工作区；启动时自动恢复；不勾选则不保存 |
| 题库导入 | 【导入题库…】选择任意 .sqlite3（同 schema）装入 banks\，下次启动生效 |
| 免 UAC | 单击即用，无需管理员权限 |

## 考试参数

CRAC：A 40题40分钟答对30 / B 60题60分钟答对45 / C 90题90分钟答对70
FCC：T 35题30分钟答对26 / G 35题30分钟答对26 / E 50题60分钟答对37

## 文件说明

    CRAC模拟考试_单文件版.exe   单文件启动器（全部内嵌）
    personal.dat                隐私数据（首次成功退出后生成；拿走/删除即清除个人数据）
    sim_app/                    展开的工作目录（含 banks\ 各题库与用户进度，可整体删除重置）

## 隐私说明

- 个人数据只存在于 personal.dat（GZip 压缩）与 sim_app\banks\ 各题库内
- 分发时删除 personal.dat 并清空 sim_app\banks\ 内的 .sqlite3 即可零隐私
- 不想保存登录信息：取消勾选"退出后保存"即可

## 已知事项

- FCC G/E 级暂为纯英文（T 级已双语），后续可扩展
- 考后"查看解析"列表中多选题显示全部勾选项与字母组合答案
- 身份证登录校验：18 位号码验证 GB11643 校验和；护照等非大陆证件格式放行
